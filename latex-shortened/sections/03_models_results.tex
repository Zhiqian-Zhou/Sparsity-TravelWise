\section{Models and headline results}
\label{sec:models}

\subsection{Model zoo}

Four families, each trained twice on identical splits with identical class-imbalance handling:
\begin{itemize}
    \item \textbf{Logistic regression}~\cite{pedregosa2011scikit} -- balanced \texttt{class\_weight}, SAGA, max 2000 iters. Strict linear baseline.
    \item \textbf{LightGBM}~\cite{ke2017lightgbm} -- 1500 trees, 63 leaves, depth 7, \texttt{scale\_pos\_weight} = train neg/pos, early stop on val PR-AUC.
    \item \textbf{XGBoost}~\cite{chen2016xgboost} -- 1500 trees, \texttt{tree\_method='hist'}, \texttt{eval\_metric='aucpr'}, early stop after 50 stagnant rounds.
    \item \textbf{GraphSAGE}~\cite{hamilton2017inductive} -- two SAGEConv layers (mean aggr) + LayerNorm + Jumping-Knowledge concat over a station graph of \num{2398} nodes / \num{163902} directed edges, MLP head, AdamW + cosine LR. PyTorch~\cite{paszke2019pytorch} + PyTorch Geometric~\cite{fey2019fast}.
\end{itemize}
Tabular models train on a multi-core CPU host; GraphSAGE on a Tesla~T4. Each \texttt{StopModel} sweeps 19 thresholds in $[0.05,0.95]$ and persists the val-F1-optimal one. Isotonic calibration is applied per (model, scenario) when val ECE $> \num{0.05}$; the threshold is then refit on calibrated probabilities.

\paragraph{Cascading respect (B/XGB).} Conditioning on the previous stop's actual disruption label,
$P(\hat{y}=1 \mid y_{k-1}=1)=\num{0.938}$ versus $P(\hat{y}=1 \mid y_{k-1}=0)=\num{0.005}$, gap $=\num{0.933}$. The model uses the inflight signal aggressively and correctly.

\paragraph{Operating points.} XGBoost~B is operationally usable as a high-precision triage signal: precision at recall \num{0.70} reaches \num{0.985}; at recall \num{0.95} it is still \num{0.548} (compared to \num{0.179} for XGBoost~A at the same recall). Performance is flat across route-position quartiles -- per-quartile PR-AUC stays in $[\num{0.935}, \num{0.954}]$.
