\subsection{Calibration}

A high PR-AUC is necessary but not sufficient: a downstream operations team will only use the predicted probabilities directly if those probabilities mean what they say. The pipeline applies isotonic-regression calibration per (model, scenario) when the validation Expected Calibration Error (ECE; ten-bin quantile) exceeds 0.05, refits the F1-optimal threshold on the calibrated validation probabilities, and re-derives the test predictions accordingly. \Cref{fig:calibration} shows the resulting reliability diagrams. After calibration, the four tree-model ECEs drop to under 0.002 (LightGBM~A 0.001, LightGBM~B 0.000, XGBoost~A 0.002, XGBoost~B 0.000); logistic regression scenario~A retains ECE 0.076 -- a residual the linear model's lower information capacity cannot smooth out.

\subsection{Per-country, per-position, per-train-class breakdowns}

\subsection{Cascading respect}

A useful sanity check on scenario~B is to ask whether the model actually \emph{uses} the inflight signal it is given. For each model we compute the binary-prediction rate conditional on the prior stop's actual disruption label, dropping the first stop of every service. A meaningful gap means the model is reading the cascade. For XGBoost~B the gap is large: $P(\hat{y}=1\mid y_{k-1}=1)=\num{0.938}$ versus $P(\hat{y}=1\mid y_{k-1}=0)=\num{0.005}$, a gap of \num{0.933}. \Cref{fig:cascading} renders the same number for every model.
