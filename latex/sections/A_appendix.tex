\subsection{Reproducibility statement}

The full pipeline is reproducible from a fresh checkout with three shell commands:

\begin{verbatim}
# Phase 0 — install dependencies (one-time)
pip install pandas numpy scikit-learn lightgbm xgboost shap matplotlib seaborn \
            pyarrow networkx jupyter papermill nbconvert torch torch_geometric \
            openmeteo-requests requests-cache retry-requests kaggle pytest \
            jpype1 install-jdk
# (jpype1 + install-jdk drive Sparksee 5.2.3 from Maven Central; see
# scripts/install_sparksee.sh which fetches the jar and a portable JDK.)

# Phase 0.5 — download raw data (one-time, ~5.7 GB)
bash scripts/download_data.sh

# Phase 1 — country preprocessing
bash preprocess/run_all_notebooks.sh

# Phase 2 — unified stop preprocessing
python stop_level/preprocess_stops.py

# Phase 3 — train + evaluate
python stop_level/train_all.py --model logreg lgbm xgb graphsage --scenario both
python stop_level/evaluate.py
python stop_level/xai_stops.py --scenario both

# Phase 5 — Knowledge Graph
python stop_level/build_kg.py --rebuild

# Phase 6 — Cause prediction
python stop_level/cause_prediction.py        # v1
python stop_level/cause_prediction_v2.py     # v2 (improved)
\end{verbatim}

The 32-test pytest suite runs in $\sim$25 seconds:

\begin{verbatim}
python -m pytest stop_level/tests/ -q
\end{verbatim}
