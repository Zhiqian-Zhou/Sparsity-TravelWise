\section{Cause-of-disruption prediction}
\label{sec:cause}

\subsection{Task definition and labelled data}

The Netherlands publishes a separate disruption-incident log that tags each event with a \texttt{cause\_group} drawn from nine mutually-exclusive classes: \emph{rolling stock, infrastructure, external, accidents, unknown, logistical, engineering work, staff, weather}. Italy and Finland do not publish equivalent labels. We construct a labelled Dutch dataset by joining each disrupted Dutch stop to the most-frequent \texttt{cause\_group} reported at the same station on the same date. The result contains \num{126810} labelled stops, which is \SI{32.2}{\percent} of all Dutch disrupted stops; the remainder are disrupted but unlabelled, an important caveat we return to in \cref{sec:discussion}.

The class distribution is severely skewed (\cref{tab:cause-classes}). Rolling stock alone accounts for almost two in five labelled stops; weather, despite being operationally important, accounts for only one in ninety.

\subsection{The v1 baseline (five models)}

We trained five multi-class classifiers on the same Phase~2 splits used for delay prediction (\num{84606} train, \num{22291} validation, \num{19913} test rows): logistic regression, LightGBM, XGBoost, random forest, and a sklearn MLP. The random forest with \texttt{class\_weight='balanced'} won validation macro-F1 (\num{0.187}). LightGBM and XGBoost recorded higher accuracy but lower macro-F1, because they were silently collapsing onto the majority class.

The per-class breakdown of the v1 winner (\cref{tab:cause-v1-perclass}) shows the failure pattern. Two of the nine classes have F1$=$\num{0.000} -- the model never predicts them. When the truth is \emph{infrastructure} the model defaults to \emph{rolling stock} \SI{65}{\percent} of the time. When the truth is \emph{weather}, it never picks weather; instead it picks rolling stock \SI{73}{\percent} and logistical \SI{27}{\percent}.

\subsection{The v2 redesign}

We targeted five specific failures of v1 with five matching changes.

\begin{enumerate}
    \item \textbf{Cause-specific feature engineering.} We added 23 features tied to known causal patterns: peak-hour flags, weekend / Monday / Friday flags, season indicators, log-transformed delay, severe-delay flags ($>$\,30 and $>$\,60 minutes), cascade indicators derived from \texttt{prev\_stop\_actual\_delay}, severe-weather flags (\texttt{weather\_severity}~$\geq$~3 and~$=$~4), a heavy-snow flag, and the interaction \texttt{winter\_x\_severe\_weather}. The interaction turned out to be the single most important addition (see results).
    \item \textbf{Symmetric sample weighting.} v1 only used \texttt{class\_weight='balanced'} on the linear and random-forest models. v2 calls \texttt{sklearn.utils.class\_weight.compute\_sample\_weight('balanced', y\_train)} once and passes the result as \texttt{sample\_weight} to LightGBM, XGBoost, random forest and gradient boosting. The gradient-boosted models now also see rare classes as expensive to misclassify.
    \item \textbf{Hyperparameter retuning.} The boosted models were retuned: 800 trees, deeper splits (\texttt{num\_leaves}~$=$~127, \texttt{max\_depth}~$=$~8 for XGBoost), and L1/L2 regularisation set to \num{0.1}.
    \item \textbf{An additional base learner.} We added sklearn's gradient boosting as a fifth base model, picked for its slightly different bias profile from XGBoost and LightGBM.
    \item \textbf{A stacking ensemble.} A logistic-regression meta-learner is fitted on the validation-set probability outputs of all five base models.
\end{enumerate}

The per-class comparison against v1 (\cref{tab:cause-perclass-comparison}) tells the more interesting story. The biggest single gain is the rare \emph{weather} class: from F1$=$\num{0.000} to F1$=$\num{0.509}, an effectively-infinite relative improvement, and the breakthrough is attributable to the single feature \texttt{winter\_x\_severe\_weather}. \emph{external} more than doubles, \emph{unknown} and \emph{logistical} roughly double. The cost is a \SI{17}{\percent} drop on the dominant \emph{rolling stock} class -- the right trade, because the v1 model was ``winning'' that class by predicting it as the default for everything.
