\section{Cause-of-disruption prediction}
\label{sec:cause}

\subsection{Task definition and labelled data}

The Netherlands publishes a separate disruption-incident log with \texttt{cause\_group} labels: 9 mutually-exclusive classes (\emph{rolling stock, infrastructure, external, accidents, unknown, logistical, engineering work, staff, weather}). Italy and Finland do not publish equivalent labels. We build a labelled NL dataset by joining each disrupted NL stop $(\texttt{station\_id}, \texttt{date})$ to the most-frequent \texttt{cause\_group} for that station on that date. The result is~\num{126810} labelled stops -- 32.2\,\% of NL disrupted stops have a matching incident-log record.

\subsection{v1 baseline (5 models)}

We trained five multi-class classifiers on the same Phase~2 splits used for delay prediction (84,606 train / 22,291 val / 19,913 test): Logistic Regression, LightGBM, XGBoost, Random Forest, MLP (\texttt{sklearn.MLPClassifier}). The Random Forest with \texttt{class\_weight='balanced'} won val macro-F1 (\num{0.187}); LightGBM and XGBoost had higher accuracy but lower macro-F1 because they were collapsing onto the majority class.

\subsection{v2 improvements}

We made five targeted changes:

\begin{enumerate}
    \item \textbf{Engineered cause-specific features (+23):} peak-hour flags, weekend / Monday / Friday flags, season indicators, log-transformed delay, severe-delay flags ($>30$ and $>60$\,min), cascade indicators (\texttt{prev\_stop\_actual\_delay}-derived), severe-weather flags (\texttt{weather\_severity}~$\geq3$ and~$=4$), heavy-snow flag, and a \texttt{winter\_x\_severe\_weather} interaction.
    \item \textbf{Sample-weight strategy applied symmetrically:} v1 used \texttt{class\_weight='balanced'} only on LogReg and RF. v2 calls \texttt{sklearn.utils.class\_weight.compute\_sample\_weight('balanced', y\_train)} and passes the result as \texttt{sample\_weight} to LightGBM, XGBoost, Random Forest and GradientBoosting. The gradient-boosted models now see rare classes as expensive to misclassify.
    \item \textbf{Hyperparameter retuning:} 800 trees, deeper (\texttt{num\_leaves}=127, \texttt{max\_depth}=8 for XGB), regularisation $\alpha=\lambda=0.1$.
    \item \textbf{Added GradientBoosting (sklearn)} as a 5th base learner with a different bias profile.
    \item \textbf{Stacking ensemble:} a Logistic Regression meta-learner fitted on the val-set probability outputs of all 5 base models.
\end{enumerate}

The headline numbers: \textbf{best test macro-F1 went from~\num{0.146} (v1) to~\num{0.213} (v2 lgbm) -- a~46\,\% relative improvement}. The price is a 17\,\% drop on the dominant \emph{rolling stock} class, which is the right trade -- the v1 model was ``winning'' by predicting the majority class for everything.

The \texttt{winter\_x\_severe\_weather} interaction is the breakthrough single feature: weather goes from F1=\num{0.000} to F1=\num{0.509} -- on the rare class with only~111 test examples, the v2 model now predicts weather correctly~51\,\% of the time. Engineering work remains unsolved (235 examples, mixed temporal pattern with logistical -- too rare and ambiguous given current features).
