\subsection{Reproducibility statement}

The full pipeline is reproducible from a fresh checkout in three shell commands. Total wall-clock time on a multi-core CPU host is approximately 1.5 hours (Phase~1 18~min, Phase~2 17~min, Phase~3 30~min, Phase~4 24~min); the 30-test pytest suite (29 passing, 1 environment-skip) runs in roughly 20 seconds.

\begin{verbatim}
# Phase 0 -- install Python dependencies (one-time)
pip install pandas numpy scikit-learn lightgbm xgboost shap matplotlib seaborn \
            pyarrow networkx jupyter papermill nbconvert torch torch_geometric \
            openmeteo-requests requests-cache retry-requests kaggle pytest \
            jpype1 install-jdk

# Phase 0a -- install Sparksee 5.2.3 (Maven Central jar) + portable Temurin JDK
source scripts/install_sparksee.sh

# Phase 0b -- download raw data (one-time, ~5.7 GB)
bash scripts/download_data.sh

# Phase 1 -- country preprocessing
bash preprocess/run_all_notebooks.sh

# Phase 2 -- unified stop-level preprocessing
python stop_level/preprocess_stops.py

# Phase 3 -- train + evaluate the four model families
python stop_level/train_all.py --model logreg lgbm xgb graphsage --scenario both
python stop_level/evaluate.py
python stop_level/xai_stops.py --scenario both

# Phase 4 -- Knowledge graph (Sparksee 5.2.3)
python stop_level/build_kg.py --rebuild

# Phase 5 -- cause-of-disruption prediction
python stop_level/cause_prediction_v2.py     # cause classifier (Section 9)

# Run the full test suite
python -m pytest stop_level/tests/ -q
\end{verbatim}

\paragraph{Versions and seeds.} Every experiment in the paper uses fixed random seeds (42 for splits, 13 for model initialisation, 42 for the SHAP subsample). Software versions are pinned in \texttt{scripts/install\_sparksee.sh} (JDK Temurin~17.0.19, Sparksee~5.2.3) and discoverable from the imports in each \texttt{stop\_level/*.py} script.
